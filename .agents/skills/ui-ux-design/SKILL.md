# UI/UX Design

Use this skill when creating or substantially redesigning a web or mobile interface.

## Workflow
1. Identify product purpose, audience, primary task, content hierarchy, constraints, and target devices. Do not invent business requirements; state assumptions.
2. Inspect the existing product and design system before changing it. Preserve established brand assets, routes, and behavior unless asked otherwise.
3. Propose a coherent visual direction: palette, typography, spacing scale, grid, component shape, imagery, iconography, and motion. Avoid generic template aesthetics.
4. Define responsive behavior at narrow, medium, and wide breakpoints.
5. Design all states: default, hover, focus, active, disabled, loading, empty, error, and success.
6. Implement semantic, accessible components. Ensure keyboard operation, visible focus, sufficient contrast, labels, and reduced-motion support.
7. Compare implementation against the brief and existing screenshots; fix visual hierarchy, alignment, rhythm, and overflow.

## Quality bar
- Use real product content rather than lorem ipsum when available.
- Use a small, consistent set of design tokens; avoid arbitrary one-off values.
- Use meaningful alt text and optimize image dimensions.
- Do not add decorative motion that impairs comprehension or performance.
- Keep layouts usable on touch screens and at 200% zoom.
